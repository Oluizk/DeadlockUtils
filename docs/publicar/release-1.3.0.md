## English

**Deadlock Utils 1.3.0**: the mod is now just a `.vpk`, and you pick the language in game.

### What's new
- **Works with mod managers**: the download is only `pak42_dir.vpk` (plus a README). Deadlock Mod Manager, Grimoire and HELLCAT install it with one click from GameBanana. No more `install.bat`.
- **Language in Settings**: shop (B) > Deadlock Utils > Settings > Language (English, Português, Español, Русский). It switches right away (shop tab, Tab items, map, tracker, rules) and is saved. English by default.

### Install
- **Mod manager:** use the 1-click install on GameBanana and launch the game from the manager.
- **Manually:** download `DeadlockUtils-v1.3.0.zip` (or just `pak42_dir.vpk`) below, copy `pak42_dir.vpk` to `Deadlock\game\citadel\addons\` and enable the addons folder in `gameinfo.gi` (steps in `README.txt`).

**Updating from 1.1/1.2 installed with `install.bat`:** just replace `game\citadel\addons\pak42_dir.vpk` with the new one (or run the old `uninstall.bat` first if you switch to a mod manager, so you don't end up with two copies).

## Português (pt-BR)

**Deadlock Utils 1.3.0**: o mod agora é só um `.vpk`, e o idioma é escolhido no jogo.

### Novidades
- **Funciona com gerenciadores de mods**: o download é só o `pak42_dir.vpk` (mais um README). Deadlock Mod Manager, Grimoire e HELLCAT instalam com um clique pelo GameBanana. Não tem mais `install.bat`.
- **Idioma nas Configurações**: loja (B) > Deadlock Utils > Configurações > Idioma (English, Português, Español, Русский). Muda na hora (aba da loja, itens no Tab, mapa, tracker, regras) e fica salvo. Inglês por padrão.

### Instalar
- **Gerenciador de mods:** use a instalação em 1 clique do GameBanana e abra o jogo pelo gerenciador.
- **Na mão:** baixe o `DeadlockUtils-v1.3.0.zip` (ou só o `pak42_dir.vpk`) abaixo, copie o `pak42_dir.vpk` para `Deadlock\game\citadel\addons\` e habilite a pasta de addons no `gameinfo.gi` (passo a passo no `README.txt`).

**Atualizando da 1.1/1.2 instalada com o `install.bat`:** é só trocar o `game\citadel\addons\pak42_dir.vpk` pelo novo (ou rode o `uninstall.bat` antigo antes, se for passar a usar um gerenciador, para não ficar com duas cópias).
