Install

  1. Close Deadlock.
  2. Download the file and extract the whole .zip to any folder (don't run it from inside the .zip).
  3. Double-click install.bat.
  4. Pick your language: 1 English, 2 Português (pt-BR), 3 Español, 4 Русский. Press Enter for English.
  5. Wait for the "Done!" message and press any key.
  6. Open Deadlock.

The installer finds your Deadlock folder, enables the mods folder in game\citadel\gameinfo.gi (with a backup) and copies the mod to game\citadel\addons\. If Windows SmartScreen shows a warning, click More info and then Run anyway.

Change the language: run install.bat again and pick another one.

Tracker

The installer shows your Steam friend code at the end. In game: shop (B) > Deadlock Utils > Settings > Tracker, paste the code and save.

After every Deadlock update

Steam restores gameinfo.gi when the game updates, which turns the mod off. Just run install.bat again.

Uninstall

Close Deadlock and double-click uninstall.bat. It removes the mod and restores your original gameinfo.gi (if you have no other mods).

Troubleshooting

  • HUD broken or not loading: run uninstall.bat. You probably have another mod that replaces hud.xml, or the game was updated and the mod needs a new version.
  • Reporting a bug: add -condebug to Deadlock's launch options on Steam, reproduce the problem and attach game\citadel\console.log to an issue on GitHub, with screenshots if possible.
  • Manual install steps (without the .bat) are in README.txt.

Português (pt-BR)

Instalar

  1. Feche o Deadlock.
  2. Baixe o arquivo e extraia o .zip inteiro em qualquer pasta (não rode de dentro do .zip).
  3. Dê dois cliques em install.bat.
  4. Escolha o idioma: 1 English, 2 Português (pt-BR), 3 Español, 4 Русский. Enter = inglês.
  5. Espere a mensagem "Pronto!" e aperte qualquer tecla.
  6. Abra o Deadlock.

O instalador acha a pasta do Deadlock, habilita a pasta de mods no game\citadel\gameinfo.gi (com backup) e copia o mod para game\citadel\addons\. Se o Windows SmartScreen mostrar um aviso, clique em Mais informações e depois em Executar assim mesmo.

Trocar o idioma: rode o install.bat de novo e escolha outro.

Tracker

No fim, o instalador mostra o seu código de amigo da Steam. No jogo: loja (B) > Deadlock Utils > Configurações > Tracker, cole o código e salve.

Depois de cada atualização do Deadlock

A Steam restaura o gameinfo.gi quando o jogo atualiza, e isso desliga o mod. É só rodar o install.bat de novo.

Desinstalar

Feche o Deadlock e dê dois cliques em uninstall.bat. Ele remove o mod e volta o gameinfo.gi ao original (se você não tiver outros mods).

Problemas

  • HUD quebrado ou não carrega: rode o uninstall.bat. Provavelmente outro mod também substitui o hud.xml, ou o jogo atualizou e o mod precisa de uma versão nova.
  • Reportar um bug: coloque -condebug nas opções de inicialização do Deadlock na Steam, repita o problema e anexe o game\citadel\console.log numa issue no GitHub, com prints se possível.
  • A instalação manual (sem o .bat) está no README.txt.
