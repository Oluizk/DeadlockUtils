## English

**Deadlock Utils 1.2.0**: a new counter editor and counters for every hero.

### What's new
- **Counters for all 44 heroes** (129 in total, up from 9 heroes). Each one is tied to the hero's kit and checked against the game's current item text and the deadlock.wiki item interactions: what Slowing Hex disables, which stuns Indomitable prevents, what Dispel Magic removes, which channels Cursed Relic or Knockdown interrupt, and more.
- **New counter editor** in the shop's look: torn-paper banners, category tabs like the shop's own, item cards, round weight buttons and less clutter.
- **Item catalog with search**: tabs for All / Weapon / Vitality / Spirit, grouped by tier with the soul cost. Search works in any language and ignores accents. Click an item to add it, click again to remove it.
- **Item details on hover**: the game-style tooltip now shows the item's description and stats (active/passive, values) in your language.
- **Fix:** Silence Wave is no longer suggested to interrupt channeled ultimates (the game says silence does not interrupt channels). Cursed Relic is suggested instead.

### Install / update
1. Download `DeadlockUtils-v1.2.0.zip` below and extract it.
2. Close Deadlock and double-click `install.bat`. Pick your language (Enter keeps the current one).

To remove: `uninstall.bat`.

## Português (pt-BR)

**Deadlock Utils 1.2.0**: editor de counters novo e counters para todos os heróis.

### Novidades
- **Counters para os 44 heróis** (129 no total; antes eram 9 heróis). Cada um está ligado ao kit do herói e foi conferido com o texto atual dos itens no jogo e com as interações de itens da deadlock.wiki: o que o Slowing Hex desativa, quais stuns o Indomitable evita, o que o Dispel Magic remove, quais canalizações o Cursed Relic ou o Knockdown interrompem e mais.
- **Editor de counters novo** no visual da loja: cartazes de papel rasgado, abas de categoria iguais às da loja, cartões dos itens, botões de peso redondos e menos poluição.
- **Catálogo de itens com pesquisa**: abas Todos / Arma / Vitalidade / Spirit, agrupados por tier com o custo em almas. A pesquisa funciona em qualquer idioma e ignora acentos. Clique num item para adicionar e de novo para tirar.
- **Detalhes do item ao passar o mouse**: o tooltip no estilo do jogo agora mostra a descrição e os atributos do item (ativo/passivo, valores) no seu idioma.
- **Correção:** o Silence Wave não é mais sugerido para interromper ultimates canalizadas (o próprio jogo diz que o silêncio não interrompe canalização). No lugar entra o Cursed Relic.

### Instalar / atualizar
1. Baixe o `DeadlockUtils-v1.2.0.zip` abaixo e extraia.
2. Feche o Deadlock e dê dois cliques em `install.bat`. Escolha o idioma (Enter mantém o atual).

Para remover: `uninstall.bat`.
