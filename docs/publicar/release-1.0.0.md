First public release of **Deadlock Utils**, an in-game HUD mod for Deadlock made with the game's own UI (Panorama). / Primeira versão pública do **Deadlock Utils**, mod de HUD para o Deadlock feito com a própria interface do jogo.

### Features
- **Shop tab**: your hero's build for the current phase, counters to the enemy team and dangerous enemy items, using the shop's own item cards.
- **Items on Tab**: counters and recommended items above the investments; owned items disappear, items you cannot buy right now are faded; click to buy.
- **Big map (M)**: the game's minimap, big, with bridge buff and mid boss timers and toggleable points of interest (healing snacks, bells, jump pads, Rem's tunnels and more). Points can also show on the regular minimap.
- **Tracker (F6)**: rank, most played heroes and your history with each player (deadlock-api.com).
- **Counter editor** with short share codes.
- **Settings**: map and minimap sizes, icons, filters, hotkeys.
- Portuguese, English and Spanish.

### Install / Instalar
1. Download `DeadlockUtils-v1.0.0.zip` below and extract it. / Baixe o zip abaixo e extraia.
2. Close Deadlock and run `Instalar.bat`. / Feche o Deadlock e rode `Instalar.bat`.
3. Tracker: shop (B) > Deadlock Utils > Settings > Tracker, enter your Steam friend code (the installer shows it). / Tracker: informe seu código de amigo da Steam em Configurações > Tracker.

Run the installer again after Deadlock updates. To remove: `Desinstalar.bat`.

### Notes / Avisos
- Replaces the game's `hud.xml`: not compatible with other mods that replace it.
- Valve has no published rules about mods. Use at your own risk.
